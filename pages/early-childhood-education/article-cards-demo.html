VPM Article Cards Component Demo

This page demonstrates the <vpm-article-cards> Shadow DOM component, showing six of the most recent stories for a single Brightspot tag and a \"View all\" button linking to that tag page.

In production, Brightspot should provide real article metadata via a JSON feed (either an inline <script type=\"application/json\" id=\"vpm-article-cards-data\"> block or a global window.vpmArticleCardsFeed variable). This demo uses simple mock data built into the component.
